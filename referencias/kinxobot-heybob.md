# KinxoBot y HeyBob

Son dos proyectos de software: KinxoBot (bot con lógica propia y base de datos) y HeyBob (app Kotlin). Se leyó su documentación y ADRs, no todo el código. Lecciones: capas con dependencias comprobadas, orquestación donde el LLM propone y el código decide, control de gasto en el gateway de LLM, y manejo cuidadoso de estado externo (Mongo/SQLite).
